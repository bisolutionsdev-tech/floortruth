# FloorTruth — judge demonstration, 180 seconds

**0:00 — Hook.** “Every large organization has feedback forms, help desks, and dashboards. But a recurring frontline issue can still disappear between shifts. FloorTruth transforms observations into evidence-linked experiments and measured learning.”

**0:20 — Capture.** Show the Signal inbox: nine **synthetic** observations, three shifts, several operational themes. Add an invented handoff observation through the capture button. “The experience should feel easy for a frontline worker—not like using a developer console.”

**0:45 — Correlate.** Enter Evidence Cases. Open Equipment Readiness. Show four or more source-linked observations. “Notice: the system does not assert a cause. It offers competing, disconfirmable hypotheses and identifies what evidence is missing.”

**1:20 — Muse Spark.** If authenticated Meta credentials and rules allow, click Ask Meta adapter to generate additional competing hypotheses. Explain that results are advisory and source-bound; if no credentials, **do not present the deterministic suggestions as Meta inference.**

**1:40 — Human governance.** Approve the simulated pilot. “A recommendation is not an authorization. This action represents the explicit human gate.”

**2:05 — Measure.** Open Experiments; use illustrative baseline 34 min, pilot 22 min, 40 shifts, $35/hr, $120 pilot cost. Show $280 modeled gross, $160 modeled net. “These are transparent synthetic assumptions—not verified causal savings.”

**2:35 — Difference.** “Existing systems collect and route feedback. FloorTruth makes the evidence, challenge, human decision, and outcome one inspectable loop. It augments judgment instead of substituting for it.”

**2:50 — Close.** “The frontline knows. The enterprise should be able to learn.”

**If model API is unavailable:** show the model-disabled status deliberately and finish the fully functional deterministic workflow. Never fabricate a model execution in a judge demo.
