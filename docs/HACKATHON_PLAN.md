## Scope discipline

**Must:** one complete loop; 2+ hypotheses; preserved citations; review gate; transparent measurement; working Meta model integration in compliant final; strong demo.

**Could:** mobile speech-to-text, issue deduplication, graph view, draft export.

**Not in hackathon:** enterprise SSO, full robotics integration, HRIS ingest, automated employee classification, production surveillance, local model hosting at scale.

## Risks and mitigations

1. **Rules prohibit pre-built code** → verify; rewrite eligible core after kickoff instead of submitting this scaffold as-is.
2. **Meta credits missing** → baseline remains runnable; verify endpoint early; do not misrepresent model use.
3. **Scope creep** → use one coherent cross-shift issue from signal to outcome.
4. **Judges doubt differentiation** → show inspectable source lineage + competing hypotheses + signed decision concept + ROI math.
5. **Privacy or IP contamination** → no employer screenshots/code/data or proprietary details in project.
6. **Power/causal overreach** → label examples synthetic and outcome estimates descriptive.
